# 🦎 Galatrixa Bot

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Galatrixa Bot** is a lightweight, agile, and versatile bot built for the community. Named after the endemic lizards of Madeira, this bot is designed to blend into your server environment while providing powerful utility, moderation, and fun features.

---

## ✨ Features

-   **🛡️ Moderation:** Keep your server safe with kick, ban, and mute commands.
-   **🎮 Fun & Games:** Interactive commands to keep your community engaged.
-   **📊 Utility:** Tools for server info, user lookups, and more.
-   **⚙️ Customizable:** Easily configure prefixes and permissions to suit your needs.

## 🚀 Getting Started

### Prerequisites

Before running the bot, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16.x or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- A Discord Bot Token from the [Discord Developer Portal](https://discord.com/developers/applications)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/NopeTheKid/galatrixa-bot.git](https://github.com/NopeTheKid/galatrixa-bot.git)
    cd galatrixa-bot
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Configure environment variables:**
    Create a `.env` file in the root directory and add your credentials:
    ```env
    TOKEN=YOUR_DISCORD_BOT_TOKEN
    PREFIX=!
    CLIENT_ID=YOUR_CLIENT_ID
    ```

4.  **Run the bot:**
    ```bash
    # For development
    npm run dev

    # For production
    npm start
    ```

## 🛠️ Commands

| Command | Description | Usage |
| :--- | :--- | :--- |
| `!help` | Displays all available commands | `!help` |
| `!ping` | Checks the bot's latency | `!ping` |
| `!clear` | Deletes a specified amount of messages | `!clear 10` |
| `!userinfo` | Shows information about a user | `!userinfo @user` |
